# 글로벌 피어 API

## API

`GET /api/v1/market/stocks/{stockCode}/global-peers`

- 지원 종목을 검증한 뒤 기존 DB 결과를 반환한다.
- 결과가 없으면 Redis 요청 제한과 종목별 생성 잠금을 거쳐 AI 서비스에 구조화 분석을 요청한다.
- 대표 피어 1개, 글로벌 피어 3개, 비교 차원 3개, 국내 기업 강점 4개, 근거·confidence·데이터 기준일·모델 메타데이터를 반환한다.
- 생성 실패, 참고 데이터 부족, 잠금 경합은 서로 다른 문제 코드로 반환하며 임의 피어로 대체하지 않는다.

## 캐시와 안전성

- PostgreSQL 캐시 키는 종목코드와 데이터 버전으로 고정한다.
- 같은 종목의 동시 생성은 Redis 분산 잠금으로 하나만 실행한다.
- 외부 입력은 OpenAI 시스템 명령으로 해석하지 않도록 명시적으로 데이터 경계 안에 넣는다.
- `0126Z0`은 검증된 재무·피어 참고 데이터가 없어 unavailable 상태를 반환한다.

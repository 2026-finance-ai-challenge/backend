# 제품 범위

## 목표

KOSPI·KOSDAQ 보통주 75개를 대상으로 한국 시장의 시세·뉴스·공시·거래 유의 정보와 세무 안내를 영어로 제공한다. 투자정보 탐색 서비스이며 주문 실행, 체결, 정산, 환전, 세무 승인 기능은 제공하지 않는다.

지원 종목, 누적 공시와 데이터 용량의 실측 스냅샷은 README에서 관리한다. 75개 종목의 기본 카탈로그는 Flyway 마이그레이션으로 제공하며 수집 데이터가 없어도 검색·탐색 범위는 유지한다.

## 데이터와 생성형 AI 원칙

- 시세·외국인 보유·뉴스·신규 공시는 KIS·KRX·Naver·OpenDART 서버 조회 결과만 사용한다.
- 값이 없거나 지연된 경우 0이나 임의 값 대신 `Unavailable`과 기준 시각·사유를 반환한다.
- OpenAI Responses API 호출은 AI 서비스에서만 수행하고 브라우저에는 키를 전달하지 않는다.
- 생성 모델과 분류 모델을 분리하고, 이벤트·감성·중요도·시장영향 분류를 OpenAI에 대체 생성시키지 않는다.
- 구조화 출력은 Pydantic/JSON Schema로 검증하고 `store=false`, 모델·프롬프트 버전·요청 ID를 기록한다.
- 뉴스·공시·사용자 입력은 신뢰할 수 없는 데이터로 취급하며 공시 답변은 고정된 접수번호·문서 버전 범위를 벗어나지 않는다.
- 목록에 필요한 뉴스·공시 제목은 수집을 막지 않는 비동기 작업으로 번역한다. 본문과 뉴스 AI Insight는 실제 사용 시 생성하고 원문 해시·언어·정책 버전으로 전 사용자에게 재사용한다.
- 본문 일괄 선번역은 하지 않으며 Redis 생성 잠금과 PostgreSQL 유일 제약으로 동시 최초 요청을 하나의 생성 작업으로 수렴한다.
- 공시 RAG는 번역본이 아닌 한글 원문을 다국어 임베딩으로 검색하고, 검색 근거만 사용해 영어 답변을 생성한다.
- 글로벌 피어 참고 데이터가 검증되지 않은 `0126Z0`은 임의 피어를 생성하지 않고 명시적인 unavailable 상태를 반환한다.
- 실시간 외부 연동은 해당 사업자 자격증명과 이용 권한이 있을 때 활성화한다.

## 서비스 구성

- Frontend: React 19, TypeScript, Vite, 비특권 Nginx
- Backend: Java 25, Spring Boot, PostgreSQL, Redis
- AI: Python 3.14, FastAPI, OpenAI Responses API, 공시 RAG 작업자
- PostgreSQL: 영속 도메인, 구조화 공시 payload, HALFVEC 검색, 감사 메타데이터
- Redis: 로그인 세션·Refresh 회전, 토큰 폐기, 요청 제한, 분산 생성 잠금

번역·공시 RAG의 생성 시점, 캐시 키, 상태 계약과 백필 기준은 [번역 캐시와 다국어 공시 RAG 설계](TRANSLATION_AND_RAG.md)를 따른다.

## 완료 기준

- 기능정의서 v2.0의 화면 흐름과 API 계약이 프로토타입에서 연결된다.
- 사용자 데이터의 모든 조회·변경에 서버 소유권 검증이 적용된다.
- 외부 데이터·AI 실패와 근거 부족 상태에서 임의 값을 표시하지 않는다.
- 단위·통합 테스트, 프로덕션 프론트 빌드, 전체 Docker 헬스체크와 보안 헤더 검증이 통과한다.

- V61로 뉴스는 공시 섹션 ID 없이 실제 `selectedText`를 저장한다. 현재 기사 원문 또는 같은 원문 해시의 READY 영어 본문과 비교하며, 다른 기사·이전 원문·요약만 완료된 캐시는 거부한다. 검증 실패는 모델 호출 전에 종료하고 재시도 버튼을 제공하지 않는다.
- 긴 기사에서도 선택 주변 문맥을 보존한다. 근거 길이를 줄일 때 직렬화된 JSON을 절단하지 않는다. 같은 멱등 키의 중복 전송, 한·영 선택, 캐시 재사용, 모델 호출 전 거부를 격리 DB에서 확인했다.
- 기사 46a5d677-544c-4bc9-9016-b8650b80e9f8의 영어 문구 `about targets and investment size have not yet been confirmed`를 실제 드래그했다. 생성 c2202fe6-3c27-4b20-9a73-7f0981111c1d는 선택문 저장·섹션 ID 없음·COMPLETED·시도 1회였다. 당시 이전 한국어 대화에 답변 언어가 영향받은 문제는 아래 질문 언어 분리에서 수정했다.
- 한글 문구 `그러나 해당 배당금이 이미 양사에 유입된 것은 아니다`의 생성 da132889-8267-4144-9fba-6ab36e7e41c2는 처음 약 30.4초 후 실패했다. 시장 Agent가 공통 SDK의 30초 제한을 상속한 것을 확인해 호출별 제한·전체 기한을 90초로 분리했다. 자동 재시도는 없으며 시간 초과·공급자 예외 종류를 원문 없이 기록한다.
- 배포 후 실패 건을 한 번 명시적으로 재시도해 34.9초에 완료했다. 응답은 아직 배당금이 입금되지 않았고 보험사 예상 수령액이 약 3조원이며 해외 투자 사용도 미확정임을 구분했다. 모델은 gpt-5-nano다. DB 시도 수는 명시적 재시도 시 초기화되므로 총 호출을 1회로 보고하지 않는다. 이 검증은 최초 실패 1회와 수정 후 재시도 1회다.
- 뉴스 번역 메모리 40c16faa-cfb5-4fee-bdc7-859e9016dfed의 READY·갱신 시각 2026-09-02 11:06:33 UTC가 유지돼 선택 질문 때문에 본문 번역이 다시 실행되지 않았음을 확인했다. 프론트는 새로고침 없이 답변과 출처 버튼을 표시했다.
- V61 적용 전 chat_generation과 스키마를 서버 0600 파일로 백업했다. 이전 이미지 `kart-backend:before-news-selection-20260903`, `kart-ai:before-agent-timeout-20260903`을 보존했다. Backend·AI 검증 이미지 모두 healthy이며 과거 HTML 백필은 중단하지 않았다.

- 뉴스·공시 드래그의 구조화된 선택 전달을 검증했다. 새 답변 언어는 화면 설정과 별개로 현재 질문에서 판별한다.
- 비로그인 세무 시작 문구는 요청된 안내 애니메이션이며 생성형 AI 결과가 아니다.
- 종목별 뉴스 헤더 가격의 KRW 고정 표기, 공시 Receiver 고정 표기, 일부 공시 목록의 현재 행 수 표기가 남아 있다.

### 9월 3일 질문 언어 분리와 대화 복원

- UI 언어를 넘겨 답변 언어로 쓰는 방식은 적용하지 않는다. 새 작업은 `answer_locale=auto`, 기존 작업의 en/ko는 보존한다. V62·V63 적용 전 생성 자료와 스키마를 0600으로 백업했다.
- 모델이 언어와 언어별 스키마를 함께 선택하던 중간 구현은 실제 영어 공시 질문을 한국어로 완료하는 실패를 보였다. 이 자기 판정 경로를 제거하고 로컬 Lingua EN/KR 판별 후 단일 언어 스키마를 고정했다. 질문의 인용문·URL·선택문·이전 대화는 언어 판별 근거와 분리한다. 언어 판별에는 유료 호출이 없다.
- KR 화면에서 `Does this filing specify both the release date and the total number of ordinary shares? State them briefly.`를 보낸 생성 b55eb033-12f6-4977-8907-54a1f057e5fd는 영어로 18,018,012주와 2026-09-05를 C1 인용과 함께 답했다.

# K-Market-Navigator Backend

외국인 투자자가 한국 상장기업 공시를 탐색하고 공시 근거를 바탕으로 질문할 수 있도록 수집·저장·조회 API를 제공하는 Spring Boot 서비스다.

현재 구현 범위는 실시간 공시 목록, 공시 상세, 공시 전용 RAG 연동으로 제한한다.
